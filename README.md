# ⚡ Turbo Tap Game | Telegram Mini App

Official Telegram WebApp for **Turbo Tap Game** featuring real-time team battle arenas, dual wallets, and strict **Binance Smart Chain (BSC BEP-20)** crypto support.

## 🚀 Features
- **Official Mascot & 3D Artwork:** High-resolution transparent PNG logo and futuristic cyberpunk design.
- **Team Battle Arena:** 3-Player ($2), 5-Player ($4), 8-Player ($7), and 12-Player ($15) lobbies with auto matchmaking radar.
- **Dual Wallets:**
  - Main Game Wallet ($25 welcome bonus)
  - Referral Bonus Wallet ($25/friend with 1-click invite link)
- **Dedicated BSC BEP-20 Deposit Address:** Deterministic, auto-generated deposit address with live QR Code.
- **Instant Withdrawals:** Minimum $20 withdrawal (3% platform fee) with automated BSC BEP-20 42-char address validation.
- **Zero Password 1-Time Sign Up:** Auto-authenticates via Telegram WebApp `initDataUnsafe`.

## 🛠️ Run Locally
```bash
node server.js
```
The server will run on `http://localhost:3000`.

## 🌐 Deploy
Deploy instantly on **Render.com**, **Railway**, or any Node.js hosting platform using `node server.js`.
